# Code de conduite

Contribuer à Voxli suppose des échanges respectueux entre humains. La
convention qui suit ([Contributor Covenant v2.1][covenant] — [FAIT] texte
de référence consulté 2026-10-18) s'applique à tous les espaces du
projet : issues, PR, discussions, chat officiel, évenements.

## Nos engageons

- Un environnement sans harcèlement : aucun comportement ou langage
  dégradant sur le genre, l'orientation, l'apparence, le handicap,
  l'appartenance ethnique ou nationale, la religion, l'âge.
- Une critique du CODE, jamais de la PERSONNE : « ce patch casse RF-22 »
  est débat ; « tu ne comprends rien » est éjecté.
- Des retours honnêtes : signaler un problème (y compris le sien !) est
  WELCOME — c'est l'esprit de la section 1 de CONTRIBUTING.md (ne jamais
  mentir sur ce qui marche).

## Responsabilités

Les mainteneurs appliquent ce code : toute conduite inacceptable
peut être signalée au mainteneur — [CANAL À COMPLÉTER : aucune adresse
non vérifiée n'est publiée ici] — avec, selon gravité : avertissement,
retrait temporaire, ban définitif.

## Portée

Y compris lors de l'usage public du projet (en ligne comme hors ligne).
